# Practice cards

The shortest useful unit of advice: one durable technique per card, with enough context to know when it applies — and when it doesn't. Cards are numbered `P-###` and never renumbered.

## Card fields

- **One-liner** — the practice in a sentence.
- **When** — the situations that trigger it.
- **Do** — the concrete moves.
- **Because** — why it works; what failure it prevents.
- **Failure signs** — how to notice you needed it.
- **Boundaries** — when it does *not* apply, or isn't worth the ceremony.
- **Provenance** — experience (journal link) or research (research/ link).

Plus the standard front-matter (`status`, `durability`, `last-reviewed`).
