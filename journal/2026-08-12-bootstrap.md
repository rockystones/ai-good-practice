# 2026-08-12 — Bootstrap

**Context.** Repo created to cultivate and update good AI-use practice: a primer and efficient learning path for smart people without a CS background, documenting a real learning path so others can pick up the lessons faster.

**Set up today.** Charter and editorial principles (durability separation, evidence grading, self-demonstration); 16-chapter syllabus in four parts; research protocol built around five framing questions, with pre-registration, lineage tracing, saturation tests, and mandatory retrospectives; source-tier guide; session templates; hygiene tooling (sensitive-info scanner + git hooks enforcing noreply identity and pre-commit/pre-push scans); practice-card format with two seed cards.

**Seed lessons carried in from experience** (source projects deliberately not named — the lessons stand alone):

- A validation gate that passes everything good is not necessarily catching anything bad; it may only ever have been tested on positives. Running negative controls exposed a gate that looked accurate and wasn't. → [P-001](../practices/P-001-negative-controls.md)
- Research sessions that start typing queries before writing down the question tend to end up answering a different, easier question. → [P-002](../practices/P-002-pre-register-the-question.md)
